# v3.6「UI 精致化与动效升级」实施计划

> 制定：2026-08-26 接手 agent。依据：docs/research/ 四份调研 + 知识库历史教训。
> 总原则：**功能稳定性第一，视觉升级第二，性能第三**。每 Phase 结束必须 `npm run build` + `npm run lint` 全绿并独立 commit/push。

## 硬约束（违反即事故）

1. 桌面端 ≥1024px 零回归
2. 移动端禁拖拽；断点体系 480/768/1024 不变；触摸目标 ≥44px
3. `prefers-reduced-motion` 降级必须保留（animations.css:113 + motion 层双保险）
4. 不引入新 UI 框架/手势库（motion 是动画库，经评估允许，见自审 Q1）
5. 每次发版同步 version.json + sw.js CACHE_VERSION（教训 #18）
6. 工作区已有的未暂存删除（README/docs 迁移遗留）不属于本任务，commit 时只 add 本次触碰的文件
