# 微交互清单（可直接抄参数）

> 调研时点：2026-08。来源：Ant Design Pro / Arco / TDesign 等成熟中后台共性 + 多篇动效指南交叉验证。
> 用法：做任何微交互前先来这里抄参数，不要现场发明时长和缓动。

## 〇、全局动效基座（先建这个）

```css
:root {
  /* 时长 */
  --dur-fast: 100ms;    /* hover/按下/focus */
  --dur-base: 180ms;    /* 常规微交互 */
  --dur-slow: 250ms;    /* 弹层/抽屉/入场 */

  /* 缓动 */
  --ease-enter: cubic-bezier(0.16, 1, 0.3, 1);     /* 入场：快起缓收 */
  --ease-exit:  cubic-bezier(0.7, 0, 0.84, 0);     /* 退场：加速离场 */
  --ease-standard: cubic-bezier(0.4, 0, 0.2, 1);   /* 状态切换（Material 标准） */
  --ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);/* 回弹强调（慎用） */
}
```

硬规则：
- **只动画 transform 和 opacity**（保 60fps；禁 width/height/top/left）
- 一切交互反馈 ≤100ms 内发生
- 入场略慢（~250ms 显从容），退场略快（~200ms 显干脆）

## Checklist 本体

### 必做项

| # | 微交互 | 参数 | 备注 |
|---|--------|------|------|
| 1 | 按钮 hover | 主按钮 `translateY(-1px)` + shadow 加深一档，100ms ease-out | 全局 CSS 可覆盖 |
| 2 | 按钮 active 按压 | `scale(0.98)` 100ms；松手回弹 | 项目已有 `.ant-card:active` 范式可扩展 |
| 3 | 按钮 loading 态 | 提交类点击立即 spinner+disabled | 防重复提交 |
| 4 | 卡片 hover | shadow 加深 + `translateY(-2px)`，150-200ms --ease-standard | 项目已统一此范式 ✓ |
| 5 | Modal 进出场 | 进 opacity+scale(0.96→1) 220ms enter；出 200ms exit | antd 内置，勿覆盖 |
| 6 | Drawer 进出场 | translateX 250ms enter / exit | antd 内置 ✓ |
| 7 | Toast/message | 顶部滑入 200ms，停 3s，淡出 150ms | antd 内置 ✓ |
| 8 | Tab 指示条 | 位移 200ms standard | antd 内置，勿覆盖 |
| 9 | Focus ring | outline 2px + offset 2px，100ms 出现 | 见 02 文档 a11y 节 |
| 10 | 表格行 hover | 背景 100ms 过渡 | antd 内置 ✓ |
| 19 | 骨架屏 shimmer | 渐变扫过 1.2-1.5s linear 循环 | antd Skeleton 内置 |
| 20 | Disabled 态 | **不做动画**，仅降透明度 | 动画让禁用显得可点 |

### 加分项

| # | 微交互 | 参数 | 备注 |
|---|--------|------|------|
| 11 | 列表/卡片流入场 | 容器 fadeUp(opacity+y16) 250ms ease-out；**stagger 间隔 40-60ms，超过 8 条停止 stagger** | motion variants 实现 |
| 12 | 数字变化 | CountUp 500-800ms + Badge 变化 200ms elastic pop | motion MotionValue，见 01 文档 §2.4 |
| 13 | Toggle/Checkbox 滑块 | 150-200ms spring | antd 内置够用 |
| 14 | Tooltip/Popover | 显示 150ms out、隐藏 100ms in（隐藏更快） | antd 默认接近 |
| 15 | 表单校验错误 | 错误文案展开 200ms + 输入框 shake 幅度 3-5px/200ms（绝不超过 20px） | 慎用 shake |
| 16 | 进度条完成 | 打勾 spring pop 300ms | — |
| 17 | 下拉刷新 | threshold 100px / maxPull 150px | 仅移动端启用 |
| 18 | 触觉反馈 | 关键操作成功 `navigator.vibrate([50])` | ⚠️ 仅 Android；iOS 静默降级 |

## 执行顺序建议

1. **第一批（零风险高回报）**：#1 #2 #9 #20 + 全局动效基座变量——全是几行 CSS
2. **第二批（体验骨架）**：骨架屏替换页面 Spin → 错误态重试 → Empty 五分类
3. **第三批（增色）**：#11 列表交错入场、#12 数字滚动、#18 触觉反馈
4. **不做的**：粒子背景、视差滚动、Lottie、大半径 blur 动画（v3.4 设计已明确排除，性能不友好）
