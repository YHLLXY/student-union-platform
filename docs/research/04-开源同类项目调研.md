## 二、四个维度的横向结论

### Dashboard 信息架构（成熟项目共性）

```
第 1 层  4 个 KPI 统计卡一排（数字大字+环比小字）
第 2 层  主图表占 2/3 宽 + 次要图表或 Top 列表占 1/3（tremor 经典 8:4 栅格）
第 3 层  待办列表——不放装饰性快捷入口九宫格，把"下一步该做什么"放首页
```

对本项目：首页 = 统计卡 + 热力缩略图 + **待我审批列表** + 近期活动。

### 任务页取舍共识

默认看板 + 右上角切表格视图；移动端自动降级为按状态分组列表（触屏拖拽体验差——与本项目 v3.5 决策一致 ✓）。

### 移动端三流派

1. 响应式单代码库（shadcn-admin 流派）← 本项目现状
2. 独立移动客户端（学之思小程序流）
3. 折中：管理端响应式即可，**抢票+签到两个高频场景做到手机优先**

### 眼前一亮的处理

- 登录页：左品牌区渐变光晕 + 右表单分屏（Hi.Events/Kan）
- 数据可视化：tremor 式**微可视化**（Sparkline 迷你线/进度环嵌进统计卡）比整块大图表高级
- 空态插画 + 行动按钮引导——中文项目通病是空态空白，是差异化机会

## 三、shadcn/tremor 生态可提炼的排版规则（翻译成 AntD）

| 规则 | 具体比例 | AntD 落地 |
|------|---------|-----------|
| 卡片留白节奏 | 内边距 24px，卡间距 16px，区块间 32px | Card padding=24，gutter=[16,16] |
| 层次靠字号不靠颜色 | 页标题 24 semibold / 卡标题 14 medium / 正文 14 / 辅助 12 muted | fontSizeHeading2=24；辅助信息统一 colorTextSecondary |
| 色彩克制 | 整页 = 主色 + 语义色 + 灰阶；图表 ≤5 色全低饱和 | 图表配色固定 token 组 |
| 统计卡公式 | 标签 12px → 数字 28-30 semibold → 环比徽章 → 微图表 | 封装 StatCard 全站复用 |
| 圆角边框 | 全局统一（卡 8/按钮 6）；1px 浅灰边框分层，阴影极淡或不用 | borderRadius=8 已定 ✓ |
| 命令面板 | ⌘K 全局跳转减少侧栏层级压力 | 远期可选 |
