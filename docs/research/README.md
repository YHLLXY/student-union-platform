## 核心结论速览

1. **动效主方案**：引入 `motion` 包（LazyMotion + m 组件 + domAnimation ≈ +20KB gzip），数字滚动用 MotionValue 零额外依赖；纯 CSS 继续负责 hover/按压等微交互
2. **令牌铁律**：语义色只从 token 取（antd `useToken()` / CSS 变量），禁止 tsx 内联 hex
3. **反馈态分工**：页面级加载用骨架屏（Spin 只用于动作提交），错误态必须带重试按钮
4. **布局参考**：Dashboard = 统计卡 → 主内容+侧栏 → 待办列表；任务页 = 看板默认 + 可切列表
5. **不可破坏的红线**：桌面 ≥1024px 零回归、移动端禁拖拽、`prefers-reduced-motion` 全局降级、触摸目标 ≥44px
