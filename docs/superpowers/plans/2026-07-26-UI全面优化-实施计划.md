- [ ] **Step 2: Bell 摇晃 — 修改 NotificationBell.tsx**

找到 `src/modules/notification/NotificationBell.tsx`。需要先读取该文件了解当前结构。

核心逻辑：当 `unreadCount` 从 0 变为 >0 时，给 Bell 图标加 CSS class 触发摇晃动画一次。

读取文件后，在 Bell 元素上添加动态 className：

```tsx
// 添加 useEffect 监听新通知
const [shake, setShake] = useState(false);
const prevCount = useRef(unreadCount);

useEffect(() => {
  if (unreadCount > (prevCount.current ?? 0)) {
    setShake(true);
    const timer = setTimeout(() => setShake(false), 600);
    prevCount.current = unreadCount;
    return () => clearTimeout(timer);
  }
  prevCount.current = unreadCount;
}, [unreadCount]);

// Bell 元素: className={`${styles.bell} ${unreadCount > 0 ? styles.bellHasUnread : ''} ${shake ? styles.bellShaking : ''}`}
```

}
