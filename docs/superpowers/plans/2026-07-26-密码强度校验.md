> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在注册/注册（教师）/重置密码时增加密码强度校验：≥8 位，必须包含字母+数字。前端 Form 规则即时提示 + Service 层二次校验形成双重保障。

**Tech Stack:** TypeScript 纯函数（正则校验）

## 风险评估与危险预案

| 风险 | 严重度 | 预案 |
|------|--------|------|
| 密码强度要求与 Supabase Auth 默认要求冲突 | 🟢 低 | Supabase Auth 默认要求密码 ≥6 位，我们的 ≥8 位更强，不冲突。如果用户从旧版注册的 6 位密码仍能登录（强度校验只作用于注册/重置，不影响登录） |
| 忘记密码流程中 `selfResetPassword()` 也接受新密码，未校验 | 🟡 中 | `selfResetPassword()` 在 `LoginPage.tsx:246` 被调用，走的是同一个 `renderPasswordStep()` 表单，前端规则已覆盖。但 Service 层没有校验——如果未来有其他地方调 `selfResetPassword()`，可能绕过校验。**处理：** 在 `selfResetPassword()` 中也加校验 |
| Form 规则 `validator` 是异步的，`validatePasswordStrength` 是同步的 | 🟢 低 | Ant Design Form 的 `validator` 接受同步返回 `Promise.resolve()/reject()`，无问题 |
| 旧注册用户密码可能是 6 位纯数字 | 🟢 低 | 强度校验只在注册/重置时触发，不影响已注册用户登录。旧用户如果密码弱，他们可以在"忘记密码"中重置——重置时也会校验新密码强度 |

- [ ] **Step 1: 在文件顶部新增导出函数**

在 `authService.ts` 的现有导出函数区域（建议放在 `checkInviteCode` 之前，第 16 行前）插入：

```typescript
/**
 * 密码强度校验
 *
 * 规则：
 *   1. 至少 8 个字符
 *   2. 必须包含至少一个字母（a-z / A-Z）
 *   3. 必须包含至少一个数字（0-9）
 *
 * 不在规则中：大小写混合、特殊字符 —— 对学生内网工具过度要求适得其反
 */
export function validatePasswordStrength(password: string): { valid: boolean; message: string } {
  if (!password || password.length < 8) {
    return { valid: false, message: '密码至少需要 8 位' };
  }
  if (!/[a-zA-Z]/.test(password)) {
    return { valid: false, message: '密码必须包含字母' };
  }
  if (!/[0-9]/.test(password)) {
    return { valid: false, message: '密码必须包含数字' };
  }
  return { valid: true, message: '' };
}
```

```typescript
export async function selfResetPassword(authId: string, newPassword: string): Promise<boolean> {
  const pwdCheck = validatePasswordStrength(newPassword);
  if (!pwdCheck.valid) {
    log.warn('selfResetPassword 密码强度不足', pwdCheck.message);
    return false;
  }

  const { error } = await supabase.rpc('reset_user_password', {
    user_id: authId,
    new_password: newPassword,
  });
  return !error;
}
```

替换为：

```tsx
<Form.Item
  name="password"
  rules={[
    { required: true, message: '请设置密码' },
    {
      validator(_, value) {
        if (!value) return Promise.resolve();
        const check = validatePasswordStrength(value);
        if (!check.valid) return Promise.reject(new Error(check.message));
        return Promise.resolve();
      },
    },
  ]}
```
