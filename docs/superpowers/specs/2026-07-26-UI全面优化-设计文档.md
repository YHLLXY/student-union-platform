# UI 全面优化 — 设计文档

> **状态：** 已批准 | **日期：** 2026-07-26 | **设计方向：** 精致极简 · 动效等级：中度增强

## 一、背景与目标

### 1.1 当前问题（审计发现）

| 问题 | 严重度 | 详情 |
|------|:--:|------|
| CSS 与主题脱节 | 🔴 高 | `theme.ts` 定义完整 token，但 17 个 CSS 文件全部硬编码颜色值，改主题 CSS 不生效 |
| 四种不同蓝色 | 🔴 高 | `#1a3a5c`(主题) / `#1890ff`(遗留) / `#3498db`(info) / `#1677ff`(PWA toast) 混用 |
| 零 keyframe 动画 | 🟡 中 | 229 个 `@keyframes` 定义为 0，仅基础 hover transition |
| 断点缺失 | 🟡 中 | 仅 768px/480px 两个断点，769-1200px 平板无适配 |
| 间距无体系 | 🟡 中 | 4~48px 任意值混用，无 4px/8px 网格 |
| 无暗色/动效偏好支持 | 🟢 低 | `prefers-color-scheme` / `prefers-reduced-motion` 完全未处理 |

### 1.2 优化目标

1. **视觉统一** — CSS 变量连接主题，消除硬编码颜色
2. **动效流畅** — 骨架屏 + 路由动画 + 微交互，消除"闪现感"
3. **专业感提升** — Header 深色渐变、卡片体系、登录页重设计
4. **响应式完善** — 平板断点 + 死代码清理
5. **性能不退化** — 动效降级、GPU 加速、不引入新依赖

---

## 二、设计决策

### 2.1 设计方向：精致极简 (Refined Minimal)

- Header: `linear-gradient(135deg, #0f2027, #203a43, #2c5364)` — 深色渐变替代 flat navy
- 卡片: 统一 10px 圆角 + 微阴影 + 1px border + 悬停 lift 2px
- 数字: 渐变色强调（统计卡片数值）
- 风格关键词: 克制、专业、留白、层次

### 2.2 动效等级：中度增强

- ✅ 轻量级基础: 骨架屏、淡入切换、数字滚动、卡片入场 (staggered fadeInUp)
- ✅ 中度增强: 路由切换 slide-fade、Bell 摇晃、看板拖拽平滑归位
- ❌ 不做: 粒子背景、视差滚动、Lottie 动画

### 2.3 关键约束

- **不改功能逻辑** — 纯 CSS + 动效层，不碰业务代码
- **渐进迁移** — CSS 变量与硬编码色值共存，逐步替换
- **动效降级** — `prefers-reduced-motion: reduce` 时禁用所有自定义动画
- **GPU 加速** — 使用 `transform`/`opacity`，避免 `width`/`height`/`top`/`left` 动画
- **每 Phase 独立验证** — `npm run build` 0 error + 手动检查

## 三、CSS 变量体系设计

### 3.1 新建文件：`src/styles/variables.css`

定义 7 组 CSS 自定义属性：品牌色、文本色、背景色、边框色、间距、圆角、阴影、动效。

### 3.2 迁移策略

1. `main.tsx` 中 `import './styles/variables.css'`
2. 各 CSS Module 文件中逐步替换：`#2c3e50` → `var(--text-primary)`
3. 主题 token 与 CSS 变量保持同步（`theme.ts` 和 `variables.css` 值一致）

---

## 四、动效体系设计

### 4.1 新建文件：`src/styles/animations.css`

| 动画名 | 用途 | 时长 |
|--------|------|:--:|
| `fadeIn` | 页面/组件淡入 | 200ms |
| `fadeInUp` | 卡片交错入场 | 250ms |
| `bellShake` | 新通知 Bell 摇晃 | 500ms |
| `shimmer` | 骨架屏扫光 | 1.5s infinite |
| `countUp` | 统计数字入场 | 300ms |

### 4.2 路由动画

在 `App.tsx` 中用 CSS class 切换实现页面 slide-fade 过渡。

### 4.3 骨架屏

在关键列表组件（Dashboard 统计卡片、TaskList、NoticeList、TicketList）中，加载态用 Ant Design `<Skeleton>` 替代 `<Spin>`。

### 4.4 降级策略

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 九、风险与缓解

| 风险 | 概率 | 缓解措施 |
|------|:--:|------|
| CSS 变量修改导致大面积样式异常 | 中 | 渐进迁移、每 Phase build 验证 |
| 动效在低端机卡顿 | 低 | GPU 加速属性 + prefers-reduced-motion 降级 |
| 路由动画与 React 懒加载冲突 | 低 | 用 CSS class 而非 JS 动画库 |
| 登录页重设计影响注册/重置密码页 | 低 | 共享 CSS 类，统一调整 |
