## 二、核心改动明细

### 修复的功能性 Bug（3 个）
1. **DashBoardPage** Promise.all 无 catch → 任一请求失败永久转圈 → 补 catch + Result 重试 UI
2. **App.tsx getCurrentUser** 无 catch → 登录态获取失败永久转圈 → 失败按未登录处理回登录页
3. **CACHE_VERSION 停留 v3.2**：v3.3~v3.5 三轮发版未同步 SW 缓存版本，线上 PWA 更新提示链断裂 → 已 bump 至 v3.6.0

### 设计令牌统一
- 110+ 处 tsx 硬编码 hex → antd `useToken()` / CSS 变量 / 共享常量，终扫残留仅 3 处合理前景白字
- 新建 `src/utils/themeColors.ts`：热力图绿阶（原两处重复）、奖牌色、模块强调色单一来源
- 看板 COLUMNS 与 constants.ts 的 TASK_STATUSES 双源合一
- theme.ts 补齐字体/文本四级/边框 token；新增 base.css 应用 body 字体与 focus-visible 焦点环
- index.html PWA Toast 内联样式收编进 base.css

### antd 6 弃用 API 迁移（25 处）
- `destroyOnClose` → `destroyOnHidden` ×20
- Statistic `valueStyle` → `styles.content` ×5

### 骨架屏体系
- 新建 `src/components/SkeletonBlocks.tsx`：RouteSkeleton / CardStreamSkeleton / ListSkeleton / DashboardSkeleton 四变体
- 13 处页面级 Spin 大转圈替换为贴近真实布局的骨架屏；弹层内部与小组件的 Spin 属合理使用予以保留

### 动效系统
- 引入 `motion`（LazyMotion strict + domAnimation），实际增量约 13KB minified（预算 25KB）
- 封装层 `src/components/motion/index.tsx` 为唯一出口：FadeIn / StaggerGroup / StaggerItem / CountUpNumber
- 落地：Dashboard 快捷卡+统计卡交错入场、三张统计数字滚动；公告/帖子/票务卡片流 CSS fadeInUp 错峰入场（delay 封顶 0.42s）
- reduced-motion 双保险：CSS @media 归零 + MotionConfig reducedMotion="user"
- 清理 animations.css 死代码类 4 个（card-enter/stat-enter/skeleton-shimmer/tap-feedback）

## 三、按计划裁剪的项（含理由）

| 裁剪项 | 理由 |
|--------|------|
| 按钮 hover 浮起微交互 | 需覆盖 antd Button 自身 transition，冲突风险 > 收益 |
| emoji 图标全量替换 | 分散 20+ 处需逐个人工选型，降级为后续建议 |
| Dashboard「待审批」上首页 | 涉及新数据流+权限边界，现有 Modal 交互成熟稳定 |
| 移动端下拉刷新 | 新依赖 + 滚动劫持风险 |
| LoginPage 563 行拆分 | 纯重构无用户可见收益 |
