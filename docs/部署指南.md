# 学生会线上交流平台 — 部署与交接指南

> 面向：接手此项目的下一任学生会技术负责人。
> 前提：你不需要是计算机专业，但需要会用浏览器、会复制粘贴命令、会注册账号。

---

## 一、项目概览

这是一个**网页应用**（PWA），用到的服务：

| 服务 | 用途 | 费用 |
|------|------|------|
| GitHub Pages | 托管网页（免费） | 免费 |
| Supabase | 数据库 + 用户登录 + 文件存储 + 实时通知 | 免费（500MB 以内） |
| GitHub Actions | 自动构建部署 | 免费 |

**不需要服务器、不需要域名、不需要花钱。**

## 三、从零部署（约 30 分钟）

### 3.1 Fork 项目到你的 GitHub

1. 打开 https://github.com/yhllxy/student-union-platform
2. 点击右上角 **Fork** → **Create fork**
3. 等几秒钟，项目就复制到你的账号下了

### 3.2 创建 Supabase 项目

1. 登录 [supabase.com/dashboard](https://supabase.com/dashboard)
2. 点击 **New project**
3. 填写：
   - Name: `student-union`（随便写）
   - Database Password: **设置一个你记得住的密码**（重要！）
   - Region: 选 **West US** 或 **Singapore**（离中国最近）
4. 点击 **Create project**，等 2 分钟让数据库启动

### 3.3 执行数据库迁移

1. 在 Supabase Dashboard 左侧菜单 → **SQL Editor**
2. 点击 **New query**
3. 打开本项目 `supabase-migration.sql` 文件，**全选复制**
4. 粘贴到 SQL Editor，点击 **Run**
5. 看到 "Success" 就完成了

### 3.4 创建存储桶

1. Supabase Dashboard 左侧 → **Storage**
2. 点击 **New bucket**
3. Name: `attachments`
4. 勾选 **Public bucket**
5. 点击 **Create bucket**

### 3.5 获取 API 密钥

1. Supabase Dashboard 左侧 → **Settings** → **API**
2. 记下两个值：
   - **Project URL**（类似 `https://xxx.supabase.co`）
   - **anon public key**（很长一串，以 `eyJ` 开头）

### 3.6 配置 GitHub Actions 自动部署

1. 打开你 Fork 的 GitHub 仓库 → **Settings** → **Secrets and variables** → **Actions**
2. 点击 **New repository secret**，添加以下 3 个：

| Name | Value |
|------|-------|
| `VITE_SUPABASE_URL` | 你的 Project URL（第 3.5 步） |
| `VITE_SUPABASE_ANON_KEY` | 你的 anon key（第 3.5 步） |
| `VITE_DEV_KEY` | 一个你自己定的开发者密钥（比如 `MYDEV2026`） |

3. GitHub 仓库 → **Actions** 标签 → 启用 Workflows
4. 推送代码触发自动部署（或手动触发 Action）

### 3.7 设置 GitHub Pages

1. GitHub 仓库 → **Settings** → **Pages**
2. Source: **GitHub Actions**
3. 保存

部署完成后，访问 `https://你的用户名.github.io/student-union-platform/` 就能看到平台了。

## 四、日常维护

### 修改代码并更新

```bash
# 1. 改代码
# 2. 本地测试
npm run dev

# 3. 构建检查
npm run build

# 4. 提交推送
git add -A
git commit -m "feat: 做了什么改动"
git push
```

推送后 GitHub Actions 会自动构建部署，约 5 分钟后线上更新。

### 修改数据库（加表/加字段）

1. 编辑 `supabase-migration.sql`，在末尾追加 SQL
2. 复制到 Supabase Dashboard → **SQL Editor** → 执行
3. 把修改后的 `supabase-migration.sql` 也提交到 Git

### 如果有人忘记密码

1. Supabase Dashboard → **Authentication** → **Users**
2. 找到那个人的邮箱（格式：`学号@stuunion.org`）
3. 点击用户 → **Reset password**（Supabase 会发重置邮件）
4. 如果邮件收不到 → 在成员管理后台**重置密码**（会生成随机密码，手动告诉他）

### 数据库备份

免费版不提供自动备份。建议每月手动导出一次，或用 Supabase CLI：
```bash
npx supabase db dump --db-url "postgres://..." > backup.sql
```

## 五、技术架构一览

```
用户浏览器
  ├─ index.html（入口）
  ├─ Service Worker（sw.js）— 离线缓存
  ├─ React App（/src/）
  │   ├─ modules/ — 功能模块（任务/公告/论坛/票务/管理）
  │   ├─ components/ — 通用组件（导航/文件上传/错误边界）
  │   └─ utils/ — 工具函数（权限/日期/文件）
  └─ 通过 Supabase JS SDK 连接
       └─ Supabase 云端
           ├─ PostgreSQL（数据库）
           ├─ Auth（用户登录）
           ├─ Storage（文件存储）
           └─ Realtime（WebSocket 实时通知）
```

**部署流程：**
```
git push → GitHub Actions → npm run build → 产出 dist/ → 部署到 GitHub Pages
```

## 六、常见问题

### Q: 注册时说"邀请码无效"
A: 检查 `invite_codes` 表 → 该邀请码是否被撤销（`revoked_at`）、已过期（`expires_at`）、已用完（`used_count >= max_uses`）。

### Q: 上传文件失败
A: 检查 Supabase Storage → `attachments` bucket 是否存在且为 Public。

### Q: 通知收不到
A: 浏览器需要 HTTPS 才能用 Service Worker 和 WebSocket（本地 `localhost` 除外）。确保访问的是 `https://...github.io/...`。

### Q: 页面打开很慢
A: Supabase 免费版数据库 7 天不活动会休眠。首次访问需要等约 2 秒。之后 PWA 缓存生效，速度正常。

### Q: 想加新功能
A: 参考 `docs/superpowers/specs/` 下的设计文档，在 `src/modules/` 下新建文件夹，复用现有 service 模式。改完后记得更新 `supabase-migration.sql`（如果加了表）。

## 七、开发环境搭建

```bash
# 1. 克隆项目
git clone https://github.com/你的用户名/student-union-platform.git
cd student-union-platform

# 2. 安装依赖（推荐用淘宝镜像）
npm install --registry=https://registry.npmmirror.com

# 3. 创建 .env.local 文件（项目根目录），内容：
VITE_SUPABASE_URL=https://你的项目.supabase.co
VITE_SUPABASE_ANON_KEY=你的anon_key
VITE_DEV_KEY=你的开发者密钥

# 4. 启动开发服务器
npm run dev

# 5. 浏览器打开 http://localhost:5173
```
