## 🎯 任务背景

**问题：** `AnalyticsDashboard.tsx` 查询 `usage_events` 表后，在前端用 `new Set()` 做 DISTINCT 去重（如 `activeUsers7d`）。当前数据量够用，但**会自动变慢**——一年后表可能 10 万行，一次性拉到前端聚合会卡死看板。

**当前实现（推测）：**
```typescript
// 拉取最近 7 天所有 usage_events → 前端 new Set() 去重
const { data } = await supabase.from('usage_events')
  .select('user_id, created_at, event_type')
  .gt('created_at', sevenDaysAgo);
// 前端：new Set(data.map(e => e.user_id)).size  // 活跃用户数
```

## ✅ 完成目标

1. 创建 SQL View `v_active_users_daily`，在数据库层做聚合。
2. `AnalyticsDashboard.tsx` 改为查询 View，前端只渲染结果。
3. 看板秒开，不再受 `usage_events` 数据量影响。

### 2. SQL View 定义

```sql
-- ============================================================
-- 第十七部分：埋点聚合 View（P1-02）
-- ============================================================

-- 1. 每日活跃用户数（最近 30 天）
CREATE OR REPLACE VIEW v_active_users_daily AS
SELECT
  DATE(created_at) AS day,
  COUNT(DISTINCT user_id) AS active_count,
  COUNT(*) AS event_count
FROM usage_events
WHERE created_at > now() - INTERVAL '30 days'
GROUP BY DATE(created_at)
ORDER BY day DESC;

-- 2. 事件类型统计（最近 30 天）
CREATE OR REPLACE VIEW v_event_stats AS
SELECT
  event_type,
  COUNT(*) AS total_count,
  COUNT(DISTINCT user_id) AS unique_users
FROM usage_events
WHERE created_at > now() - INTERVAL '30 days'
GROUP BY event_type;

-- 3. 最近 7 天活跃用户数（标量，用于卡片显示）
-- 不单独建 View，直接查询 v_active_users_daily 的最近 7 天 SUM
```

### 3. AnalyticsDashboard.tsx 改动点

把原来的"拉全表 + 前端聚合"改为：

```typescript
// 查询最近 7 天活跃用户数（从 View 查）
const [{ data: dailyData }, { data: eventStats }] = await Promise.all([
  supabase.from('v_active_users_daily').select('*').limit(7),
  supabase.from('v_event_stats').select('*'),
]);

// 7 天活跃用户 = 最近 7 天 distinct user_id 总数
// 注意：直接 SUM(active_count) 会重复计算（同一用户多天算多次）
// 需要：7 天活跃 = 最近 7 天的 distinct user_id 数
// View 无法直接给这个标量，所以仍需一次原始查询：

const { data: active7d } = await supabase
  .from('usage_events')
  .select('user_id')
  .gt('created_at', new Date(Date.now() - 7 * 86400000).toISOString())
  .not('user_id', 'is', null);

const activeUsers7d = new Set(active7d?.map(e => e.user_id)).size;
```

**说明：** 7 天活跃用户这个指标本质上需要 DISTINCT 跨天去重，View 按天聚合后仍需前端二次去重。但因为只拉 `user_id` 一列（7 天数据量有限），比原来拉全表轻得多。

**更好的方案（推荐）：** 建一个 RPC 返回标量：
```sql
CREATE OR REPLACE FUNCTION get_active_users_7d()
RETURNS INTEGER
LANGUAGE sql
SECURITY DEFINER
SET search_path = public
AS $$
  SELECT COUNT(DISTINCT user_id)::INTEGER FROM usage_events
  WHERE created_at > now() - INTERVAL '7 days';
$$;
```

前端：
```typescript
const { data: active7d } = await supabase.rpc('get_active_users_7d');
const activeUsers7d = active7d ?? 0;
```
