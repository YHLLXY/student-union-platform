## 🎯 任务背景

**学生会痛点：** 每次会议都要纸质签到，统计出勤率费时，且出勤率直接影响评优。

**功能价值：** 扫码签到 + 自动统计 + 出勤率排名，替代纸质签到表。

## ✅ 完成目标

1. 部长创建会议 → 生成签到二维码。
2. 成员扫码签到（自动记录时间）。
3. 部长查看签到名单 + 出勤率统计。
4. 主席团看全校出勤率排名。

## 🚧 硬约束

1. **遵循 CLAUDE.md 模块结构规范**：`modules/checkin/` 下 `index.tsx` + `CheckinService.ts` + 组件 + css。
2. **不引入新路由**（在已有页面内通过 Card/Tab 展开，或征得同意后加路由）。
3. **不引入二维码生成库**（用 `qrcode.react` 或纯前端 canvas 实现，需征得同意）。
4. 复用现有权限模型（`hasMinRole` + RLS）。
5. 复用现有通知机制（会议创建时通知部门成员）。

## ⚠️ 注意

本任务是**新功能开发**，规模较大。建议：
1. 先做最小可用版本（MVP）：创建会议 + 扫码签到 + 查看名单。
2. 出勤率统计、排名等作为后续迭代。

````markdown
### 2. 数据库表设计

```sql
-- ============================================================
-- 第二十部分：会议签到（P2-03）
-- ============================================================

-- 1. 会议表
CREATE TABLE IF NOT EXISTS meetings (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  title TEXT NOT NULL,
  description TEXT,
  meeting_time TIMESTAMPTZ NOT NULL,
  location TEXT,
  department TEXT NOT NULL,           -- 主办部门
  participating_departments TEXT[] DEFAULT '{}',  -- 参与部门
  created_by UUID REFERENCES users(id),
  created_at TIMESTAMPTZ DEFAULT now(),
  status TEXT DEFAULT 'active'        -- active | ended | cancelled
);

-- 2. 签到记录表
CREATE TABLE IF NOT EXISTS checkin_records (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  meeting_id UUID REFERENCES meetings(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id),
  checked_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE(meeting_id, user_id)         -- 防重复签到
);

CREATE INDEX IF NOT EXISTS idx_checkin_meeting ON checkin_records(meeting_id);

-- 3. RLS 策略
-- 会议：本部门 + 参与部门 + 管理员可读；dept_head+ 可创建
-- 签到记录：自己 + 会议创建者 + 管理员可读；已登录用户可创建自己的
```

### 3. CheckinService.ts 接口设计

export interface Meeting {
  id: string;
  title: string;
  description: string;
  meeting_time: string;
  location: string;
  department: string;
  participating_departments: string[];
  created_by: string;
  created_at: string;
  status: string;
}

export interface CheckinRecord {
  id: string;
  meeting_id: string;
  user_id: string;
  user_name?: string;  // 联表查
  checked_at: string;
}

// 函数列表
export async function fetchMeetings(department: string): Promise<Meeting[]>
export async function createMeeting(meeting: Omit<Meeting, 'id' | 'created_at' | 'status'>): Promise<Meeting | null>
export async function fetchMeetingDetail(meetingId: string): Promise<Meeting | null>
export async function fetchCheckinRecords(meetingId: string): Promise<CheckinRecord[]>
export async function checkin(meetingId: string, userId: string): Promise<{ success: boolean; message: string }>
export async function fetchMyCheckinIds(userId: string): Promise<Set<string>>
```

### 4. 签到流程

```
部长创建会议 → 会议详情页显示二维码（编码 meeting_id）
成员扫码 → 跳转 /checkin?meeting=xxx → CheckinPage 显示会议信息 + 签到按钮
点击签到 → checkin() → 成功提示
部长刷新 → 看到签到名单
```
````
