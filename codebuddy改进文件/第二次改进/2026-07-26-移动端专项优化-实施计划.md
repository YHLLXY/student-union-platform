# 移动端专项优化 — 实施计划

> **For agentic workers:** 直接按 Task 顺序执行。Steps 用 checkbox (`- [ ]`) 跟踪。每个 Task 后 `npm run build` 验证 + 移动端尺寸抽查。
>
> **前置阅读：** 先读 `2026-07-26-移动端专项优化-设计文档.md` 的「核心约束」和「待确认决策」。

**Goal:** 系统性优化 13 模块移动端体验，仅移动断点内生效，桌面端零回归，移动端无拖拽。

**Architecture:** 复用 v3.4 的 CSS 变量层 → 增补移动端变量 → 全局布局安全区 → 重灾区（Kanban 点击模式 + 表格卡片化）→ 其余模块断点补齐 → 触摸打磨。纯 CSS + 少量 TSX 断点判断，不引入新依赖。

**Tech Stack:** React 19 + Ant Design 6（`Grid.useBreakpoint()`）+ CSS Modules + CSS Custom Properties

**核心约束：**
- 🔒 所有改动在 `@media (max-width: 1024px)` 内或 `useBreakpoint()` 判断内生效，桌面端不动
- 🔒 移动端不允许拖拽（Kanban / 文件上传改点击）
- 🔒 不引入新 UI 框架 / 手势库

**项目根目录：** `E:\homework\开发\Claudecode\学生会交流平台`

- [ ] **Step 1: 新建 `MobileCardList.tsx`**

通用组件：接收 `columns`（同 AntD Table columns）+ `dataSource` + `rowKey`，渲染移动端卡片列表。

```tsx
// 简化结构
export function MobileCardList({ columns, dataSource, rowKey, onRow }: Props) {
  return (
    <div className={styles.mobileList}>
      {dataSource.map((row) => (
        <div key={row[rowKey]} className={styles.mobileCard} onClick={() => onRow?.(row)}>
          {columns.filter(c => c.dataIndex).map(col => (
            <div key={col.key} className={styles.mobileField}>
              <span className={styles.mobileLabel}>{col.title}</span>
              <span className={styles.mobileValue}>
                {col.render ? col.render(row[col.dataIndex], row) : row[col.dataIndex]}
              </span>
            </div>
          ))}
        </div>
      ))}
    </div>
  );
}
```
